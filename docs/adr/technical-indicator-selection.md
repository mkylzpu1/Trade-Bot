# テクニカル指標一覧（個人投資家向け）

| テクニカル指標名 | 分類 | 重要度 | 概要 | 算出方法 | 実装要否 | 備考 |
|---|---|---|---|---|---|---|
| 移動平均線（SMA） | トレンド系 | ★★★★★ | 一定期間の平均価格を表す | SMA = 期間内終値の合計 ÷ 期間 | - | ゴールデンクロス・デッドクロス |
| 指数移動平均線（EMA） | トレンド系 | ★★★★★ | 直近価格を重視した移動平均線 | EMA = 前日EMA + α × (当日終値 − 前日EMA) | - | MACD算出に利用 |
| 移動平均乖離率 | トレンド系 | ★★★★★ | 移動平均線からの乖離度を示す | 乖離率 = (終値 − SMA) ÷ SMA × 100 | - | 国内個人投資家に人気 |
| MACD | トレンド系 | ★★★★★ | 短期・長期EMAの差でトレンド転換を判断 | MACD = EMA12 − EMA26 | - | シグナル線とのクロス利用 |
| 一目均衡表 | トレンド系 | ★★★★★ | トレンド・支持線・抵抗線を総合判断 | 転換線、基準線、先行スパン等を算出 | - | 日本で非常に人気 |
| DMI | トレンド系 | ★★★★☆ | 上昇・下降トレンドの方向性を判断 | +DI、-DIを算出 | - | ADXと併用 |
| ADX | トレンド系 | ★★★★☆ | トレンドの強さを判断 | DMIから算出 | - | トレンド相場判定 |
| パラボリックSAR | トレンド系 | ★★★★☆ | トレンド転換点を判断 | SAR = 前SAR + AF × (EP − 前SAR) | - | 損切り判断にも利用 |
| RSI | オシレーター系 | ★★★★★ | 買われすぎ・売られすぎを判断 | RSI = 上昇幅平均 ÷ (上昇幅平均 + 下落幅平均) × 100 | - | 70・30が目安 |
| ストキャスティクス | オシレーター系 | ★★★★★ | 価格の位置関係を判断 | %K = (終値−安値)/(高値−安値)×100 | - | クロスシグナル利用 |
| RCI | オシレーター系 | ★★★★★ | 日付順位と価格順位の相関を見る | スピアマン順位相関係数 | - | 日本で人気 |
| CCI | オシレーター系 | ★★★★☆ | 平均価格からの乖離を判断 | (TP−TP平均)/(0.015×平均偏差) | - | 順張り・逆張り両対応 |
| サイコロジカルライン | オシレーター系 | ★★★★☆ | 投資家心理を判断 | 上昇日数 ÷ 期間 × 100 | - | シンプル |
| MFI | オシレーター系 | ★★★★☆ | 出来高を加味したRSI | 資金流入量・流出量から算出 | - | 出来高分析向け |
| ボリンジャーバンド | ボラティリティ系 | ★★★★★ | 値動きの幅を判断 | SMA ± (標準偏差 × 2) | - | 利用者非常に多い |
| %B | ボラティリティ系 | ★★★★☆ | ボリンジャーバンド内での現在位置 | (終値−下限)/(上限−下限) | - | BB補助指標 |
| Band Width | ボラティリティ系 | ★★★★☆ | ボラティリティの大きさを判断 | (上限−下限)÷中心線 | - | スクイーズ判定 |
| ATR | ボラティリティ系 | ★★★★☆ | 値動きの大きさを判断 | True Rangeの移動平均 | - | 損切り設定向け |
| 出来高 | 出来高系 | ★★★★★ | 売買の活発度を判断 | 約定数量の合計 | - | 全指標の基本 |
| VWAP | 出来高系 | ★★★★★ | 出来高加重平均価格 | Σ(価格×出来高) ÷ Σ出来高 | - | デイトレ必須級 |
| OBV | 出来高系 | ★★★★☆ | 出来高と価格変動の関係を見る | 累積出来高を計算 | - | トレンド確認 |
| VR（Volume Ratio） | 出来高系 | ★★★★☆ | 売買エネルギーを見る | 上昇出来高 ÷ 下落出来高 | - | 国内利用あり |
| 騰落レシオ | 市場分析系 | ★★★★☆ | 市場全体の過熱感を判断 | 値上がり銘柄数 ÷ 値下がり銘柄数 × 100 | - | 日本市場で有名 |
| Fibonacci Retracement | サポレジ系 | ★★★☆☆ | 押し目・戻り目を予測 | フィボナッチ比率適用 | - | 人気高い |
| Pivot Point | サポレジ系 | ★★★☆☆ | 支持線・抵抗線を算出 | (高値+安値+終値)÷3 | - | デイトレ向け |
| Donchian Channel | サポレジ系 | ★★★☆☆ | ブレイクアウトを判断 | n期間最高値・最安値 | - | トレンドフォロー向け |
