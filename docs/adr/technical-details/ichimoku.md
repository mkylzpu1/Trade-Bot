# 一目均衡表（Ichimoku Cloud）

## 概要
一目均衡表は、トレンド・モメンタム・サポート/レジスタンス・時間分析を一つのチャートで総合的に判断できる日本発のテクニカル指標です。
複数の線と「雲（クモ）」により、相場の全体像を直感的に把握できます。

---

## この指標でわかること
- トレンド
  → 価格と雲の位置関係で上昇・下降を判断できる

- 過熱感
  → 価格が雲から大きく乖離すると過熱の可能性

- ボラティリティ
  → 雲の厚みで相場の変動幅を把握

- 投資家心理
  → 雲が抵抗帯として機能し「意識される価格帯」を可視化

---

## 算出方法

一目均衡表は以下の5本のラインで構成されます。

### 計算式
- 転換線（Conversion Line）
  =（過去9期間の高値 + 安値） / 2

- 基準線（Base Line）
  =（過去26期間の高値 + 安値） / 2

- 先行スパン1
  =（転換線 + 基準線） / 2 を26期間先にシフト

- 先行スパン2
  =（過去52期間の高値 + 安値） / 2 を26期間先にシフト

- 遅行スパン
  = 当日の終値を26期間過去へシフト

---

### 計算例
例：価格データから

- 9期間高値/安値 → 転換線 = 150円
- 26期間高値/安値 → 基準線 = 140円

先行スパン1 = (150 + 140) / 2 = 145円（26日先へ）
先行スパン2 = 135円（26日先へ）

→ 雲（クモ）形成

---

## 基本的な見方
- 価格 > 雲 → 上昇トレンド
- 価格 < 雲 → 下降トレンド
- 雲の中 → レンジ・迷い相場

また、
- 転換線 > 基準線 → 短期強気
- 転換線 < 基準線 → 短期弱気

---

## チャートで見る代表的なシグナル

### 買いシグナル
- 価格が雲を上抜け
- 転換線が基準線を上抜け（ゴールデンクロス）

→ 上昇トレンド開始の可能性

---

### 売りシグナル
- 価格が雲を下抜け
- 転換線が基準線を下抜け（デッドクロス）

→ 下降トレンド開始の可能性

---

### トレンド継続判定
- 価格が雲の上で推移
- 遅行スパンが価格より上

→ 強い上昇トレンド継続

---

## 有効な相場
- トレンド相場：非常に有効
- レンジ相場：ダマシが増える
- 長期相場：特に有効（機関投資家向け）

---

## 組み合わせると良い指標
- 出来高（ブレイク確認）
- RSI（過熱感補助）
- MACD（トレンド補助）
- ボリンジャーバンド（ボラティリティ補助）

## Trade-Bot実装観点

### 必要データ
- 高値
- 安値
- 終値
- 過去52期間以上の履歴

### 算出頻度
- 日足〜時間足（短期はノイズ増加）

### 実装難易度
- ★★★★☆（複数ライン・シフト処理あり）

### シグナル化候補
- 雲上抜け → 買い
- 雲下抜け → 売り
- 転換線クロス → 補助シグナル
- 遅行スパン位置 → フィルター
