# Trade-Bot

## 概要

Trade-Bot は、テクニカル指標を利用した株式自動売買を実現するためのオープンソースソフトウェア（OSS）です。

### 主な機能

- 株価のリアルタイム監視
- テクニカル指標の算出
- 売買シグナルの判定
- 注文発注

ローカルPC上で動作するため、証券口座情報や注文情報を**開発者が管理する外部サーバー**へ送信することなく利用できます。

## 背景・目的

本プロジェクトの調査範囲において、移動平均線、MACD、RSIなどのテクニカル指標のシグナルを利用した株式自動売買を無料で利用できるOSSは確認できなかった。

そのため、Trade-Bot はテクニカル指標を利用した自動売買環境をオープンソースとして提供し、誰でも無料で利用できるプラットフォームの構築を目的とする。

また、本プロジェクトは以下の2つの観点を目的としている。

### 1. ユーザー向け目的
テクニカル指標に基づく売買シグナルを用いた自動売買環境を、無料かつオープンな形で提供すること。

### 2. 開発者（有志）向け目的
GitHubを中心としたチーム開発を前提とし、利用者自身が売買ロジックや機能を自由に追加・拡張できるOSSとして設計すること。
